# 💇 Primo Smart Salon (v1)

`Static Site` `HTML/CSS/JS` `Salon & Beauty` `4.9★ Rated`

> Madanapalle's 4.9★ rated unisex hair & style salon.

## What is this?

An earlier revision of [primo-smart-salon](https://github.com/mynampatiasha/primo-smart-salon) —
hair styling, hydra facials, straightening, waxing, and appointment
booking, with `.backup` copies of the HTML/CSS kept alongside the live files.

## ✨ Highlights

- ⭐ 4.9★ rating showcased
- 💆 Full service list (styling, facials, straightening, waxing)
- 📅 Appointment booking call-to-action

## 🛠️ Tech Stack

Static **HTML**, **CSS**, and vanilla **JavaScript** — no build step, no framework.

## 📁 Structure

```
index.html / index.html.backup   # the page and its backup
index.css / index.css.backup     # styles and its backup
index.js                          # page behavior
assets/                            # images
```

## 🚀 Running Locally

```bash
python -m http.server 8000
```
